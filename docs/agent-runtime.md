# 助手执行与上下文

助手页面使用短请求提交和读取状态；模型调用在独立 `agent` Redis 连接的 `panel_agent` 队列中执行。专用 Supervisor 程序为 `buncloud-agent`，不复用或重启现有 Horizon 队列。新对话界面的模型生成没有固定时长上限，任务和专用执行器的超时均为 0；一直等待完成、主动停止或真实连接错误。每次生成最多三轮工具查询，仍保留连接建立超时、输出大小和权限检查。PHP-FPM 的 30 秒限制保持不变，不承载后台模型生成。

执行中每 30 秒续期 Redis 的 240 秒任务租约，防止长时间生成被重复领取；租约不是生成时限。仅运行中任务连续 240 秒没有执行器心跳才标记为进度中断，排队时间不会触发生成失败。执行器的 `max-time` 和 `max-jobs` 仅在当前任务结束后检查，用于进程回收，不打断当前生成。旧同步 `agent/chat` 仍受 Web 请求生命周期限制，客户端应使用 `agent/start` 与进度接口。

模型请求使用原生 PHP cURL 读取 SSE。页面每秒读取一次执行状态，隐藏页面时降到三秒，完成后停止轮询。显示实际连接、推理状态、工具开始/完成、返回记录数、模型公开摘要与渐进回答。`reasoning_content` 仅为 DeepSeek 同轮工具续接保留在工作进程内，不发给浏览器、不写日志和会话；不从私密推理编造摘要。已输出内容后模型失败不自动切换模型拼接答案。

生成期间可停止；停止标记会由 cURL 进度回调检查。取消不撤销此前已批准的修改，生成或查询本身不执行节点写入。预览、逐项批准、幂等确认和撤销仍使用原应用服务。每次工具执行会重新核对当前工具授权。

会话与任务在缓存内加密保存，按管理员 ID 隔离，24 小时过期。浏览器只在 sessionStorage 保存不含内容的会话/任务 ID。刷新可恢复当前会话和任务；新对话不携带旧上下文。模型最多接收最近八轮完整对话和 32KB 历史上下文，旧对话移出上下文，界面明确显示轮数及遗漏量；失败和取消的轮次不进入下一次模型上下文。界面最多保留十六轮及 512KB 会话数据。

历史预览仅携带有限对象引用，不向模型重放批准 Token、密钥或私密推理。历史状态不是新的写入授权，也不作为当前在线状态；涉及当前状态要重新查询。刷新批准卡片时按管理员匹配操作回执，避免已批准操作重新显示为待批准。

审计日志仍记录助手请求路径，但 `agent/start` 和旧 `agent/chat` 的提问正文会脱敏，不与会话缓存重复保存。

生产安装模板：`deploy/buncloud-agent.conf`。当前宝塔 Supervisor 的实际配置目录为 `/www/server/panel/plugin/supervisor/profile/`（使用 `.ini` 扩展名），控制命令为 `/www/server/panel/pyenv/bin/supervisorctl -c /etc/supervisor/supervisord.conf`。部署只更新 `buncloud-agent` 程序，不修改现有 `v` 程序和定时备份。
